# 🌱 Agro AI

**Рақамӣ ёрдамчии деҳқони тоҷик** — цифровой помощник фермера Таджикистана.
Flutter-приложение для Android и iPhone. Работает **без интернета**, на таджикском и русском.

## Две версии

| | **Agro AI Offline** | **Agro AI** (online) |
|---|---|---|
| Распознавание болезней | Своя нейросеть в телефоне (TFLite) | Gemini (бесплатный ключ) / Claude, без сети — своя модель |
| Интернет | Не нужен, разрешения INTERNET нет | Для AI и погоды |
| Погода и совет по поливу | — | Open-Meteo, 12 городов Таджикистана |
| Фото уходят из телефона | Никогда | Только в выбранный AI-сервис |

## Возможности
- **Дашборд**: шапка с градиентом, анимированные графики доходов/расходов за 6 месяцев, структура расходов.
- **Участки и сезоны**: площадь, почва, посевы с прогрессом до сбора, урожайность кг/га.
- **Скан растения**: анимация сканирования, шкала уверенности, лечение и профилактика из своей базы.
  Защита от ошибок: если на фото не лист (клубень, плод, земля), приложение так и скажет, а не придумает диагноз.
- **Полив**: история, план, напоминания (07:00, Asia/Dushanbe), совет по погоде (online).
- **Дневник**: расходы/доходы по категориям, урожай с автоматической записью дохода.
- **Справочник**: 8 культур Таджикистана.
- **Демо-хозяйство** одной кнопкой — для презентаций.

## Своя модель (офлайн)
- MobileNetV3-Large, дообучение на открытых данных, экспорт в TFLite (~3,3 МБ).
- Данные: PlantVillage (CC BY-SA) — 9 культур; SAR-CLD-2024 — хлопок (CC BY 4.0);
  Wheat Leaf Dataset — пшеница (CC BY 4.0); Caltech-101 — класс «не лист» (CC BY 4.0).
- Обучение в облаке: `.github/workflows/train.yml` → `tools/train/train.py`.
- Двойная защита от ложных диагнозов: класс «не лист» + проверка доли цвета листа на фото.

## Данные и надёжность
- **SQLite** (`agro_ai.db`): таблица на сущность, индексы по участку и дате, все изменения — в
  транзакции, режим WAL, версия схемы и миграции. Пишутся только изменённые записи.
- Автоматический перенос старых данных из JSON при обновлении; если SQLite недоступна — работа на JSON.
- **Автокопии** раз в сутки, 7 последних, восстановление в «Настройки → Данные и безопасность».
- Экспорт/импорт копии файлом. Ключи API в копию не попадают.
- **Без падений**: глобальный перехват ошибок, журнал ошибок на телефоне, дружелюбный экран вместо краша.

## Структура
```
lib/
  core/        тема, навигация, локализация (tg/ru), валидация, конфигурация версии
  models/      plot, crop_cycle, irrigation, transaction, harvest, plant_scan
  data/local/  SQLite / JSON хранилища, миграция
  data/remote/ Gemini и Claude клиенты
  services/    ai, offline (модель + база болезней), погода, уведомления, бэкапы, журнал ошибок, демо
  features/    home, plots, plant_scan, irrigation, farm_diary, knowledge, settings
assets/data/   справочник культур и база болезней (tg/ru)
assets/models/ модель TFLite и список классов
tools/train/   обучение модели
```

## Сборка
```bash
flutter test
flutter build apk --release --split-per-abi --flavor offline
flutter build apk --release --split-per-abi --flavor online
flutter build ios --release --no-codesign --dart-define=EDITION=offline   # на macOS
```
CI: `build.yml` (анализ, тесты, обе версии, подпись), `ios.yml` (iPhone), `train-model` (модель).
Установка на iPhone без Mac: [docs/IOS_SIDELOAD_RU.md](docs/IOS_SIDELOAD_RU.md).
