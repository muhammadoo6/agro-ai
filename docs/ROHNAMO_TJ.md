# Agro AI — роҳнамои пурраи лоиҳа (барои муаллиф ва ҷавоб ба жюри)

> Ин ҳуҷҷатро на аз ёд, балки **бо фаҳмиш** омӯзед. Ҳар бахшро бо файли коди худ муқоиса кунед —
> роҳи файл дар назди ҳар мавзӯъ навишта шудааст. Жюри ҳамеша аз «чаро?» мепурсад, на аз «чӣ?».

---

## 1. Лоиҳа дар як нафас (30 сония)

**Agro AI** — барномаи мобилӣ барои деҳқони тоҷик. Деҳқон аз барги растанӣ акс мегирад ва
**нейрошабакаи худии мо дар худи телефон, бе интернет** бемориро муайян карда, табобат тавсия медиҳад.
Ғайр аз ин, барнома қитъаҳо, мавсимҳо, обёрӣ, хароҷот ва даромад, ҳосил, обу ҳаво ва дониш дар бораи
зироатҳоро нигоҳ медорад. Ду версия дорад: **Offline** (тамоман бе интернет) ва **Online**
(иловатан Gemini-и ройгон ва обу ҳаво). Дар **Android** ва **iPhone** кор мекунад, бо тоҷикӣ ва русӣ.

## 2. Мушкилот ва барои кӣ

| Мушкилот | Ҳалли мо |
|---|---|
| Дар деҳот агроном кам аст, маслиҳат дер мерасад | Ташхис дар 1–2 сония, дар телефон |
| Дар бисёр деҳот интернет суст ё нест | Модели худӣ бе интернет кор мекунад |
| Деҳқон хароҷот ва даромадро дар дафтар менависад ва гум мекунад | Дафтари рақамӣ, графикҳо, нусхаи эҳтиётӣ |
| Барномаҳои хориҷӣ бо тоҷикӣ нестанд | Интерфейс бо тоҷикӣ ва русӣ |

**Корбарон:** деҳқонони хурд ва миёна, хоҷагиҳои деҳқонӣ (дехқонӣ), агрономҳо, ширкатҳои калон
(бисёр қитъа, ҳисобот).
**Даромад (модел):** версияи асосӣ ройгон; версияи Pro барои хоҷагиҳои калон (ҳисоботҳо, сервер,
ҳамоҳангсозии чанд телефон); шартнома бо ширкатҳои пахтакорӣ ва фурӯшандагони доруи растанӣ.

## 4. Меъморӣ (архитектура)

Лоиҳа ба қабатҳо ҷудо шудааст — ҳар қабат танҳо бо қабати поёнӣ гап мезанад:

```
Экранҳо (lib/features/…)            ← чизе ки деҳқон мебинад
      ↓
Репозиторияҳо (lib/data/repositories) ← қоидаҳои кор: нигоҳ доштан, ҳисоби даромад
      ↓
Анборҳо ва хизматҳо                   ← SQLite, файлҳо, модели TFLite, Gemini, обу ҳаво
(lib/data/local, lib/data/remote, lib/services)
```

| Папка | Чӣ дорад |
|---|---|
| `lib/main.dart` | оғози барнома: база, модел, огоҳинома, журнали хатоҳо |
| `lib/core/` | танзимот: версия (`app_config.dart`), мавзӯи ранг, тарҷума, санҷиши майдонҳо |
| `lib/models/` | моделҳои додаҳо: қитъа, мавсим, обёрӣ, амалиёт, ҳосил, скан |
| `lib/data/local/` | SQLite ва файлҳо |
| `lib/data/remote/` | клиентҳои Gemini ва Claude |
| `lib/data/repositories/` | `FarmRepository` (хоҷагӣ), `SettingsRepository` (танзимот) |
| `lib/services/` | AI, нусхаи эҳтиётӣ, обу ҳаво, огоҳинома, модели офлайн |
| `lib/features/` | экранҳо: асосӣ, қитъаҳо, скан, обёрӣ, дафтар, донишнома, танзимот |
| `assets/` | модели `.tflite`, рӯйхати синфҳо, базаи бемориҳо, роҳнамои зироатҳо (JSON) |
| `tools/train/` | скриптҳои Python барои омӯзиш ва санҷиши модел |
| `test/`, `integration_test/` | тестҳо |

**Ду версия (flavor):** як код, ду барнома. Дар Android — `--flavor offline/online`
(`android/app/build.gradle.kts`), дар iOS — `--dart-define=EDITION=offline/online`.
Версияи Offline ҳатто иҷозати интернет надорад (`android/app/src/offline/AndroidManifest.xml`).

## 5. Пойгоҳи додаҳо (база)

**Файл:** `lib/data/local/sqlite_farm_store.dart`

- **SQLite** — базаи релятсионии дохили телефон (файли `agro_ai.db`). Сервер лозим нест.
- **6 ҷадвал:** `plots` (қитъаҳо), `cycles` (мавсимҳо), `irrigations` (обёрӣ),
  `transactions` (хароҷот/даромад), `harvests` (ҳосил), `scans` (сканҳо) + `meta` (версияи схема).
- **Сохтори ҳар ҷадвал:**

| Сутун | Тип | Маъно |
|---|---|---|
| `id` | TEXT PRIMARY KEY | рақами ягонаи сабт |
| `plot_id` | TEXT | ба кадом қитъа тааллуқ дорад |
| `date` | TEXT | сана (барои ҷустуҷӯ ва тартиб) |
| `data` | TEXT (JSON) | ҳамаи майдонҳои сабт |
| `updated_at` | INTEGER | вақти охирин тағйир |

- **Индексҳо:** `plot_id` ва `date` дар ҳар ҷадвал — ҷустуҷӯ тез мешавад.
- **WAL (Write-Ahead Logging):** хондан ва навиштан ҳамзамон; агар барнома ногаҳон баста шавад, база вайрон намешавад.
- **Транзаксияҳо:** ҳар тағйир «ё пурра, ё ҳеч» сабт мешавад.
- **Навиштани танҳо фарқ (diff):** баъди тағйир на ҳамаи база, балки танҳо сабтҳои тағйирёфта навишта мешаванд (`farm_repository.dart`).
- **Миграция:** версияи схема дар `onUpgrade`; маълумоти версияи кӯҳна (JSON) худкор ба SQLite гузаронида мешавад (`farm_store_factory.dart`).
- **Нусхаи эҳтиётӣ** (`backup_service.dart`): ҳар рӯз худкор, 7 нусхаи охирин нигоҳ дошта мешавад; содирот ба файл ва барқарорсозӣ.
  Навиштан аввал ба файли муваққатӣ ва баъд иваз кардан — файл ҳеч гоҳ «нимнавишта» намемонад.

**Чаро ҷадвал + JSON?** Сутунҳое ки аз рӯи онҳо ҷустуҷӯ мекунем (`plot_id`, `date`) — алоҳида ва бо индекс;
дигар майдонҳо дар JSON. Ин имкон медиҳад майдони нав илова кунем бе тағйири схема.

**Чаро на Firebase ё сервер?** Деҳқон интернет надорад; маълумоти хоҷагӣ шахсӣ аст ва бояд дар телефони ӯ бимонад.

| Иҷозатҳои зиёдатӣ | Иҷозатҳои нолозим (ҳолати телефон, хотираи умумӣ) **маҷбурӣ хориҷ** шудаанд | `android/app/src/main/AndroidManifest.xml` |

| Хатои ногаҳонӣ | Ҳамаи хатоҳо ба журнал навишта мешаванд, барнома намепарад, ба корбар паёми фаҳмо нишон дода мешавад | `lib/services/error_log.dart`, `main.dart` |

**Ростқавлона — чӣ ҳоло нест (ва нақша):**
- Калиди API дар хотираи хусусии барнома нигоҳ дошта мешавад, вале **рамзгузорӣ нашудааст**.
  Қадами навбатӣ: Android Keystore / iOS Keychain (`flutter_secure_storage`).
- Базаи SQLite рамзгузорӣ нашудааст (SQLCipher — қадами навбатӣ). Аммо файл дар минтақаи
  хусусии барнома аст — барномаҳои дигар онро хонда наметавонанд.
- Ҳисоби корбар (логин) нест — чунки сервер нест; ин сатҳи ҳамларо кам мекунад.

### 7.2 Омӯзиш (Transfer Learning — омӯзиши интиқолӣ)

1. **MobileNetV3-Large**, ки аллакай дар ImageNet (1,2 млн акс) шаклҳо ва рангҳоро шинохтааст, гирифта мешавад.
2. **Марҳилаи 1 (3 эпоха):** қабатҳои асосӣ ях карда мешаванд, танҳо «сар»-и нав (Dropout 0.3 + Dense 70 + softmax) меомӯзад. Adam, lr = 0.001.
3. **Марҳилаи 2 (6 эпоха):** 100 қабати болоӣ кушода мешаванд ва бо lr = 0.00001 (1000 маротиба хурдтар) нозук танзим мешаванд. BatchNormalization ях мемонад.
4. **Афзоиши додаҳо (augmentation):** гардиш, оина, зум, равшанӣ, контраст — то модел аксҳои гуногунро шиносад.
5. **Вазни синфҳо (class weights, то 5):** синфҳои кам (масалан, картошкаи солим) нодида гирифта намешаванд.
6. **Аксҳои саҳроӣ 6 маротиба такрор** карда мешаванд — то модел на танҳо аксҳои лабораторӣ, балки саҳроро омӯзад.
7. **Табдил ба TFLite** бо квантизатсия (`Optimize.DEFAULT`) → **3,3 МБ**.
8. Омӯзиш дар абр (GitHub Actions) ~**2,5 соат** давом кард (ҳадди вақт дар код: то 5 соат 20 дақ, баъд худаш қатъ мекунад).

### 7.4 Ҳифзҳо дар барнома (`lib/services/offline/offline_diagnoser.dart`)

- **Шинохтани мева/сабзавот:** агар дар акс лӯндаи картошка, помидор, бодиринг ва ғ. бошад (боварӣ ≥ 55%) → «Ин: Картошка»
  ва маслиҳат: барои ёфтани беморӣ акси баргро гиред.
- **Синфи «барг нест»:** акси даст, хона, ашё → «барг ёфт нашуд», на бемории сохта.
- **Санҷиши ранги барг:** агар дар акс камтар аз 8% ранги барги зинда бошад → «барг нест».
- **Ҳадди боварӣ 55%:** агар модел боварӣ надорад, ростқавлона «боварӣ нест» мегӯяд ва 3 варианти беҳтаринро нишон медиҳад.
- **TTA (Test-Time Augmentation):** акс ва нусхаи оинавии он таҳлил ва натиҷаҳо миёна карда мешаванд.
- **Маслиҳати зироат:** агар деҳқон зироатро нависад, танҳо бемориҳои ҳамон зироат баррасӣ мешаванд (71%).

### 7.5 Версияи Online (Gemini)

`lib/services/ai_service.dart`, `lib/data/remote/gemini_api_client.dart`
- Акс + дастур ба Gemini фиристода мешавад, ҷавоб бо **JSON-схемаи қатъӣ** (ташхис, нишонаҳо, табобат, пешгирӣ, дараҷа).
- Барнома аввал аз Google рӯйхати моделҳоеро мепурсад, ки **ба ҳамин калид** дастрасанд, ва моделро худаш интихоб мекунад.
  Агар модел ҷавоб надиҳад (404 — нест, 429 — лимит), модели навбатӣ санҷида мешавад; модели корӣ дар хотир мемонад.
- **Санҷиши калид:** баъди ворид кардан барнома дархости кӯтоҳ мефиристад ва мегӯяд: «Калид кор мекунад» ё сабаби
  аниқ (калид нодуруст, минтақа, лимит, интернет нест).
- Агар интернет набошад, калид нодуруст ё лимит тамом шуда бошад — **худкор ба модели худӣ мегузарад**.

## 8. Сифат ва тестҳо

- **77 тести худкор** (`test/`): моделҳо, база, ҳисоби даромад, нусхаи эҳтиётӣ, Gemini, модели офлайн, санҷиши майдонҳо.
- **Тестҳои интегратсионӣ** (`integration_test/`): тамоми роҳи деҳқон дар телефон; боркунии модел дар симулятори iPhone.
- **CI/CD** (`.github/workflows/`): ҳар тағйир → `flutter analyze` (0 хато) → тестҳо → скриншотҳо → APK бо имзо.
- **Хатои воқеӣ, ки ёфтем:** дар iPhone китобхонаи кӯҳнаи TFLite 2.12 модели навро кушода наметавонист. Тест дар симулятор хаторо исбот кард, ба 2.17 гузаштем — тест гузашт.

| Маълумот танҳо дар як телефон | сервер ва ҳамоҳангсозӣ (Pro) |
| Калид рамзгузорӣ нашудааст | Keystore/Keychain |

## 10. Саволҳои эҳтимолии жюри ва ҷавобҳо

**1. Ин лоиҳа аз «ChatGPT-и оддӣ» чӣ фарқ дорад?**
Мо нейрошабакаи **худиро** омӯзонидем — модели 3,3 МБ дар худи телефон, бе интернет. ChatGPT интернет ва сервер талаб мекунад.

**2. Нейрошабака чист, бо забони содда?**
Функсияи калон бо миллионҳо рақам (вазн). Ба он ҳазорҳо акси барг бо ҷавоби дуруст нишон медиҳем; он вазнҳоро тағйир медиҳад, то хатояш кам шавад.

**3. Transfer learning чаро?**
Омӯзиш аз сифр миллионҳо акс ва ҳафтаҳо вақт мехоҳад. Мо моделеро гирифтем, ки шаклу рангро аллакай медонад ва онро ба бемориҳо омӯзонидем.

**4. Чаро MobileNetV3, на ResNet?**
MobileNet барои телефон сохта шудааст: ~5 млн параметр, тез. ResNet-50 ~25 млн параметр, вазнин ва суст.

**5. Эпоха чист? Learning rate?**
Эпоха — як бор дидани ҳамаи аксҳо. Learning rate — қадами тағйири вазнҳо: калон — тез вале ноустувор, хурд — оҳиста вале дақиқ. Барои ҳамин дар марҳилаи 2 1000 маротиба хурдтар гирифтем.

**6. Overfitting чист ва чӣ тавр пешгирӣ кардед?**
Вақте модел аксҳоро аз ёд мекунад, на қоидаро. Ҳифз: Dropout 0.3, augmentation, санҷиш дар аксҳои нодида.

**7. Дақиқии 96% аз куҷо?**
8 136 акси санҷишӣ, ки модел надидааст: 95,9%. Ростқавлона: дар саҳро 60% (84% дар 3 ҷавоб) — ин ҳам дар слайд ҳаст.

**8. Агар акси картошка (лӯнда) гиранд?**
Ҷавоб: «Ин: Картошка» — модел 26 намуди мева ва сабзавотро мешиносад (97%). Баъд маслиҳат медиҳад, ки
барои ташхиси беморӣ акси баргро гиред. Агар ашёи дигар бошад — «барг ёфт нашуд».

**9. Пиёз ё тарбузро мешиносад?**
Не, модел 11 зироатро медонад. Зироати нав = аксҳо + омӯзиши нав (~6 соат). Версияи Online бо Gemini ҳар растаниро таҳлил мекунад.

**10. Чаро SQLite?** Бе сервер, бе интернет, дар ҳар телефон ҳаст, транзаксия ва индекс дорад.

**11. WAL чист?** Тағйирҳо аввал ба журнали алоҳида навишта мешаванд; агар барқ равад, база вайрон намешавад.

**12. Маълумот гум шавад-чӣ?** Нусхаи эҳтиётии ҳаррӯза (7 нусха), содирот ба файл ва барқарорсозӣ.

**13. Амнияти маълумот?** Offline иҷозати интернет надорад; HTTPS; калид дар сарлавҳа ва берун аз нусхаи эҳтиётӣ; иҷозатҳои нолозим хориҷ; APK имзо шудааст.

**14. Заифии амниятӣ дорад?** Ҳа, ростқавлона: калиди API ва база рамзгузорӣ нашудаанд — қадами навбатӣ Keystore ва SQLCipher.

**15. Чаро Flutter?** Як код барои Android ва iOS; суръати баланд; дастгирии Google.

**16. Барнома чӣ тавр сохта мешавад?** GitHub Actions: тафтиш → тестҳо → сохтан → имзо. Барои iPhone — компютери Mac дар абр.

**17. Чаро модел дар абр омӯхта шуд?** Омӯзиш ~55 000 акс ва ~6 соат вақт мехоҳад; компютери абрии 8 ГБ.

**18. Даромад аз куҷо?** Версияи Pro барои хоҷагиҳои калон, шартнома бо ширкатҳо ва фурӯшандагони нуриҳо/доруҳо, грантҳои агросоҳа.

**19. Рақобатчиён?** Plantix ва дигарон — одатан бо тоҷикӣ нестанд, барои ташхис интернет мехоҳанд ва дафтари хоҷагӣ надоранд. Мо — ҳар се дар як барнома.

**20. Оё AI-асбобҳо истифода шуданд?**
Ростқавлона ҷавоб диҳед. Имрӯз ҳар барномасоз асбобҳои ёрирасон (AI, ҷустуҷӯ, ҳуҷҷатҳо) истифода мебарад. Муҳим — шумо медонед, ки чӣ сохта шуд, чаро ин тавр, ва онро тағйир дода метавонед. Пеш аз озмун қоидаҳоро хонед: баъзан бояд истифодаи AI-ро эълон кард.

**21. Метавонед ҳозир ягон чизро тағйир диҳед?** (Жюри метавонад санҷад!)
Машқ кунед: дар `app_strings.dart` матнро иваз кунед → `r` (hot reload) → тағйир дар экран. Ё дар `offline_diagnoser.dart` `minConfidence`-ро тағйир диҳед ва фаҳмонед, чӣ мешавад.
