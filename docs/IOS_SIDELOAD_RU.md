# Установка Agro AI на iPhone без Mac и без платного аккаунта

Это способ для **своего** iPhone (проверка, показ). Раздать приложение другим людям так
нельзя: для этого Apple требует аккаунт разработчика ($99 в год).

## Что нужно
- Компьютер с Windows и кабель для iPhone.
- Обычный Apple ID (тот же, что в App Store).
- Файл `AgroAI-Offline-iOS-unsigned.ipa` (собирается в облаке, лежит в папке `release`).

## Один раз: подготовка компьютера
1. Установите **iTunes** и **iCloud** с сайта apple.com (именно с сайта, *не* из Microsoft Store).
2. Скачайте и установите **Sideloadly** с официального сайта sideloadly.io.

## Установка
1. Подключите iPhone кабелем, разблокируйте, на вопрос «Доверять этому компьютеру?» нажмите **Доверять**.
2. Откройте Sideloadly. Ваш iPhone появится в списке.
3. Перетащите файл `AgroAI-Offline-iOS-unsigned.ipa` в окно Sideloadly.
4. В поле **Apple account** введите свой Apple ID, нажмите **Start**, при запросе введите пароль
   и код подтверждения. (Пароль уходит только в Apple — так работает подпись.)
5. На iPhone: **Настройки → Основные → VPN и управление устройством** → выберите свой Apple ID →
   **Доверять**.
6. На iOS 16 и новее включите **Настройки → Конфиденциальность и безопасность → Режим разработчика**,
   iPhone перезагрузится.
7. Откройте **Agro AI** на iPhone.

## Ограничения бесплатного Apple ID
- Приложение работает **7 дней**. Потом подключите iPhone к компьютеру и снова нажмите Start в
  Sideloadly (данные в приложении сохранятся).
- Не больше 3 таких приложений одновременно.
